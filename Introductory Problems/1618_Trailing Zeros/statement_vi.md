# 1618 - Chữ số 0 ở cuối

* **Giới hạn thời gian:** 1.00 s
* **Giới hạn bộ nhớ:** 512 MB

Nhiệm vụ của bạn là tính số chữ số 0 ở cuối của giai thừa $n!$.

Ví dụ, $20!=2432902008176640000$ và nó có $4$ chữ số 0 ở cuối.

# Dữ liệu vào

Dòng duy nhất chứa một số nguyên $n$.

# Kết quả

In ra số chữ số 0 ở cuối của $n!$.

# Giới hạn

* $1 \le n \le 10^9$

# Ví dụ

Dữ liệu vào:

```cpp
20
```

Kết quả:

```cpp
4
```
