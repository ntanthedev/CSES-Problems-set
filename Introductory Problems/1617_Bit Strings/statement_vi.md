# 1617 - Xâu nhị phân

* **Giới hạn thời gian:** 1.00 s
* **Giới hạn bộ nhớ:** 512 MB

Nhiệm vụ của bạn là tính số lượng xâu nhị phân có độ dài $n$.

Ví dụ, nếu $n=3$, đáp án đúng là $8$, vì các xâu nhị phân có thể có là 000, 001, 010, 011, 100, 101, 110, và 111.

# Dữ liệu vào

Dòng duy nhất chứa một số nguyên $n$.

# Kết quả

In ra kết quả modulo $10^9+7$.

# Giới hạn

* $1 \le n \le 10^6$

# Ví dụ

Dữ liệu vào:

```cpp
3
```

Kết quả:

```cpp
8
```
