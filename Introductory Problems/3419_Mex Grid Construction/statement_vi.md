# 3419 - Mex Grid Construction

* **Giới hạn thời gian:** 1.00 s
* **Giới hạn bộ nhớ:** 512 MB

Nhiệm vụ của bạn là xây dựng một lưới $n \times n$ mà mỗi ô vuông chứa số nguyên không âm nhỏ nhất không xuất hiện ở bên trái trên cùng hàng hoặc ở phía trên trên cùng cột.

# Dữ liệu vào

Dòng duy nhất chứa một số nguyên $n$.

# Kết quả

In ra lưới theo ví dụ.

# Giới hạn

* $1 \le n \le 100$

# Ví dụ

Dữ liệu vào:

```cpp
5
```

Kết quả:

```cpp
0 1 2 3 4
1 0 3 2 5
2 3 0 1 6
3 2 1 0 7
4 5 6 7 0
```
