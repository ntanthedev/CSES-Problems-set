# 2105 - Xâu Con Phân Biệt

* **Giới hạn thời gian:** 1.00 s
* **Giới hạn bộ nhớ:** 512 MB

Đếm số lượng xâu con phân biệt xuất hiện trong một xâu.

# Dữ liệu vào

Dòng đầu tiên chứa một xâu có độ dài $n$ gồm các ký tự a–z.

# Kết quả

In ra một số nguyên: số lượng xâu con.

# Giới hạn

* $1 \le n \le 10^5$

# Ví dụ

Dữ liệu vào:

```cpp
abaa
```

Kết quả:

```cpp
8
```

Giải thích: các xâu con là `a`, `b`, `aa`, `ab`, `ba`, `aba`, `baa` và `abaa`.
