# 2110 - Phân bố xâu con

* **Giới hạn thời gian:** 1.00 s
* **Giới hạn bộ nhớ:** 512 MB

Cho một xâu có độ dài $n$. Với mỗi số nguyên từ $1 \ldots n$, bạn cần in ra số lượng xâu con phân biệt có độ dài tương ứng.

# Dữ liệu vào

Dòng duy nhất chứa một xâu có độ dài $n$ gồm các ký tự a–z.

# Kết quả

Với mỗi số nguyên từ $1 \ldots n$, in ra số lượng xâu con phân biệt có độ dài đó.

# Giới hạn

* $1 \le n \le 10^5$

# Ví dụ

Dữ liệu vào:

```cpp
abab
```

Kết quả:

```cpp
2 2 2 1
```
